## 1. Project Overview / Problem Statement & Approach

Signal-to-Shock is a financial event intelligence prototype that converts
unstructured financial text into structured risk signals and demonstrates
how major events could affect a synthetic portfolio.

The system is being developed to analyze financial sentiment, classify
events, assign transparent impact scores, and simulate event-driven
portfolio stress scenarios.

## 2. Architecture & Tech Stack

Python, Streamlit, Pandas, NumPy, and modular ingestion, NLP and risk
components. The architecture diagram will be stored at docs/architecture.png.

## 3. Dataset Used

The initial portfolio data is synthetic. Additional synthetic news and
social-media fixtures will be documented in the data/ directory.
No confidential client data is used.

## 4. Quickstart & Installation

Runtime: Python 3.12.
