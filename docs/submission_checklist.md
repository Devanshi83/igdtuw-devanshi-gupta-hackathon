# Submission checklist

Based on the supplied four-page S&P Global & CRISIL Campus Hackathon 2026 guidelines. This is a local readiness checklist, not an official acceptance certificate.

| Requirement | Repository status / remaining action |
|---|---|
| Public GitHub repo with required naming | Target repository verified PUBLIC through GitHub on 19 October 2026; verify final pushed contents while logged out |
| Working source, architecture, setup/run commands | Included; fresh-install verification documented |
| 5–7 slide PDF/PPTX | Seven-slide PDF and editable PPTX at docs/presentation.* |
| College name, candidate and college email | Included in README and title slide |
| 10-minute demo screen recording | **Pending:** record, upload YouTube Unlisted, verify logged-out playback and add README URL |
| Prototype inputs in data/ | Synthetic inputs, scenario definitions, market cache and checksums included |
| Data source clarity | data/README.md and evaluation documents separate synthetic and public sources |
| LICENSE | Complete MIT software license; research data retains original terms |
| README template | Overview, architecture, dataset, quickstart and results included |
| Repository hygiene and incremental commits | Runtime outputs, licensed sentence outputs, environments and caches ignored |
| Individual submission and AI integrity | Candidate named and AI assistance disclosed |
| Original case-study alignment | **Pending:** original case brief has not been provided; current framing follows the project handoff |
| Official deadline | **Pending:** confirm exact date/time from organizer email/portal; do not infer it from an earlier extension mention |
| Final submission form | **Pending:** submit repo, video and deck links and retain acknowledgement |
| Live pitch if shortlisted | Attend scheduled session and rehearse docs/jury_qa.md |

Run `python scripts/check_submission.py` to check package files/links/checksums. Run with `--strict` to additionally reject a missing YouTube URL. These commands cannot verify the video's visibility, deadline, original brief or form completion.

Do not mark the submission complete while required external actions remain.
